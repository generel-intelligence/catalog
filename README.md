# Generel Intelligence benchmark catalog

This repository will provide provenance-rich metadata about third-party AI
benchmarks maintained by their original owners.

## Status

Pre-alpha. M0 establishes governance only; no benchmark entries are included
yet.

The catalog records official sources, ownership, licenses, versions, and
adapter status. It does not copy benchmark datasets or private Generel
Intelligence suites, rubrics, solutions, or evaluators.

Catalog corrections are welcome when they cite an authoritative upstream
source.
