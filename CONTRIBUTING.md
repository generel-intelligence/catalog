# Contributing

This repository is pre-alpha. Current public contributions are limited to
governance, documentation, and catalog corrections supported by authoritative
upstream sources. Do not submit copied benchmark content or future adapter
implementation.

Follow the canonical
[organization contribution policy](https://github.com/generel-intelligence/.github/blob/main/CONTRIBUTING.md).

Every commit must include a Developer Certificate of Origin `Signed-off-by`
trailer. Use `git commit -s`.
